# AI SupportFlow

AI-powered customer support automation built using n8n, LLMs, webhooks and PostgreSQL.

## Objective

Automatically process customer support messages, classify them using an LLM, determine priority and sentiment, and store structured ticket information in a database.

## Planned Workflow

Customer Message
→ n8n Webhook
→ Input Validation
→ LLM Classification
→ Structured JSON
→ Priority Routing
→ PostgreSQL
→ Response

## Tech Stack

- n8n
- OpenAI / Claude
- Python
- PostgreSQL / Supabase
- Git & GitHub
